# E-Commerce Sales Dashboard - Power BI

## Project Overview
This project analyzes e-commerce sales data using Microsoft Power BI.
The dashboard provides an interactive view of sales, profit, orders,
products, and overall business performance.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Power BI Skills Practiced
- Data Import and Transformation
- Data Cleaning
- Data Visualization
- DAX Measures
- KPI Cards
- Slicers and Filters
- Interactive Dashboard Creation

## Dashboard Features
- Sales Analysis
- Profit Analysis
- Product Performance
- KPI Cards
- Interactive Filters and Slicers

## What I Learned
- How to transform and analyze data in Power BI
- How to create DAX measures
- How to build interactive dashboards
- How to use KPIs and visualizations to present business insights
